# AVDEN-Studio (AV-CORE & Panel Editor)

**Открытый, вендоронезависимый HTML-first фреймворк и визуальный WYSIWYG-редактор для создания сенсорных интерфейсов управления AV-оборудованием (Node-RED, Wiren Board, Crestron, Q-SYS, AMX).**

> **Проект:** AVDEN-Studio · **Автор и создатель архитектуры:** Вяхирев Алексей Алексеевич (Alexey A. Vyakhirev) · 2026

## Философия и ключевые особенности

Проект создан как современная открытая альтернатива традиционным инструментам разработки AV-интерфейсов (Crestron Construct, VTPro-e, Node-RED Dashboard) и построен на пяти фундаментальных принципах:

1. **LLM-Native & Human-in-the-Loop (Стек для нейросетей и инженеров).**
   Архитектура изначально спроектирована для генерации экранов и виджетов с помощью больших языковых моделей (LLM) по спецификации [`AV-SKILL.md`](AV-SKILL.md). Нейросеть генерирует чистый семантический HTML/CSS без проприетарных форматов, а встроенный визуальный редактор (**Panel Editor**) обеспечивает точную ручную доводку, привязку сигналов и контроль целостности.
2. **Pure HTML-First & Declarative Data-Contracts.**
   HTML-разметка является единственным источником истины. Вся логика взаимодействия (кнопки, слайдеры, навигация, вкладки, мульти-списки, маршрутизация видео, удержание пресетов) описывается декларативно через канонические `data-*` атрибуты без написания бизнес-логики на JavaScript.
3. **Vendor-Agnostic Dual Transport (Абстракция транспорта).**
   Интерфейс полностью изолирован от протокола контроллера. Единый слой сигналов (`Digital`, `Analog`, `String`, `Smart`) работает поверх:
   - **WebSocket** (универсальный JSON-протокол для Node-RED, Q-SYS, AMX, Python-бэкендов);
   - **Crestron** (`CrComLib` / `WebXPanel`);
   - **Mock** (встроенный локальный имитатор ответов контроллера для автономной отладки и демо).
4. **In-Browser WYSIWYG IDE & Clean Export.**
   Визуальный редактор (`panel-editor.js`) подключается непосредственно к рабочей панели в браузере. Поддерживает живую правку геометрии (Smart Guides, групповое выравнивание), реестр join-ов, менеджер кнопок с несколькими визуальными состояниями, а при экспорте автоматически вырезает свой UI, сбрасывает сцену в исходный «первый кадр» и проверяет сохранённый файл в изолированном `iframe`.
5. **Field-Ready Commissioning (Инженерная диагностика на объекте).**
   В интерфейс встроен автономный терминал пусконаладки: живой журнал сигналов `TX/RX`, визуальные бейджи join-ов поверх элементов, генератор тестовых RX-команд и защита статических надписей от перезаписи (`data-text-lock`).

## Быстрый старт

Проект не требует сборки, Node.js или облачных серверов — достаточно любого статического веб-сервера или локального открытия файла в браузере.

### 1. Режимы запуска (URL-параметры)
- **Подключение к Node-RED / универсальному WebSocket:**
  `index_1.html?transport=ws&ws=ws://192.168.1.49:1880/socket`

> **Важное замечание по настройке WebSocket:**  
> По умолчанию адрес WebSocket-сервера зашит в начале ядра `av-core.js` в константе:
> ```javascript
> var DEFAULT_WS = 'ws://192.168.1.49:1880/socket';
> ```
> Указать свой адрес сервера или контроллера можно любым из четырёх способов (в порядке приоритета):
> 1. **Через URL-параметр:** `?ws=ws://<ваш-ip>:<порт>/socket`
> 2. **В разметке HTML:** добавить атрибут `data-ws-url="ws://..."` на корневой контейнер `#panel-stage`
> 3. **В рантайме (из скрипта или консоли):** вызвать `Panel.use('ws', { url: 'ws://...' })`
> 4. **Постоянно в коде:** изменить значение `DEFAULT_WS` в файле `av-core.js`


### 2. Горячие клавиши Panel Editor
- `E` — включить / выключить режим визуального редактирования (выключить перед экспортом)
- `J` — показать / скрыть бейджи join-сигналов поверх элементов
- `S` — выделить активный экран / диалог
- `Tab` — скрыть / показать боковую панель инспектора
- `H` — скрыть / показать верхнюю панель инструментов
- `O` — включить / выключить отступ и масштабирование холста
- `Ctrl + Z` / `Ctrl + Y` — отмена и повтор действий
- `Ctrl + S` — чистый экспорт проекта в автономный `.html` файл (выключить редактирование перед экспортом)


### 3. Подключение библиотек Crestron (опционально)
Репозиторий не содержит проприетарных файлов Crestron (`cr-com-lib.*.js`, `webxpanel.*.js`).
* В режимах `mock` и `ws` (Node-RED, Q-SYS, AMX) интерфейс работает полностью автономно без сторонних библиотек.
* Для работы в нативном режиме `crestron` поместите скомпилированный файл `cr-com-lib.*.js` рядом с `index_1.html` — в разметке шаблонов он уже прописан **перед** ядром `av-core.js`:
  ```html
  <!-- ═══════════ ЯДРО ═══════════ -->
  <script src="cr-com-lib.21e0d0c2.js"></script>
  <script src="av-core.js"></script>
  ```

### 4. Включение и повторное подключение визуального редактора (`panel-editor.js`)
При экспорте проекта из **Panel Editor** (кнопка **«💾 Сохранить»** или `Ctrl + S`) редактор автоматически вырезает свой интерфейс и тег `<script id="pe-script">`, чтобы итоговый HTML-файл был чистым и готовым к загрузке на сенсорную панель.

Чтобы сделать любой HTML-файл (новый или ранее сохранённый) снова редактируемым:
1. Откройте HTML-файл в любом текстовом редакторе.
2. Убедитесь, что строка подключения `panel-editor.js` добавлена **после** `<script src="av-core.js"></script>` и **перед** закрывающим тегом `</body>` (в шаблонах `index_*.html` — сразу после блока отладчика, перед комментарием модуля видеостены):
   ```html
   <script src="av-core.js"></script>
   <!-- ... код отладчика ... -->
   <script src="panel-editor.js" id="pe-script"></script>
   <!-- ═══════════ МОДУЛЬ ВИДЕОСТЕНЫ ═══════════ -->
   ```
3. Откройте файл в браузере и нажмите клавишу **`E`** (или кнопку **«✎ Правка»** в верхней панели).

> **Важно:** обязательно указывайте атрибут `id="pe-script"` — по нему экспортер находит и аккуратно удаляет загрузчик редактора при сохранении чистого продакшн-файла.


## Управление окнами и элементами по WebSocket

Окна, диалоги и элементы управления изменяют своё состояние по командам с контроллера или из Node-RED через простые JSON-сообщения. Join могут быть числовыми или именованными. Сообщения (тип сигнала, имя join и значение) также поступают от панели по WebSocket при действиях пользователя.

1. **Показать экран** с `join = "page.audio"`:
   `{"type":"digital","join":"page.audio","value":1}`
2. **Сделать кнопку визуально активной:**
   `{"type":"digital","join":"222","value":1}`
3. **Установить слайдер на 17%:**
   `{"type":"analog","join":"2","value":17}`
4. **Управление видимостью (`Visibility Join`):** если в редакторе для элемента задан `data-visibility-join`, его можно скрывать и показывать значениями `0` и `1` (`{"type":"digital","join":"...","value":0}`).
5. **Кнопки с несколькими состояниями (`AVStates`):** текущий визуальный вид переключается через их `Analog Join` (`{"type":"analog","join":"...","value":2}`).




## Управление адресной книгой и списками по WebSocket

Динамические списки (например, телефонная книга ВКС с `data-list-join="phonebook"`) управляются с контроллера или из Node-RED через JSON-сообщения типа `smart`. Каждой строке автоматически назначаются текстовые join-ы вида `book.<number>.name`, `book.<number>.desc`, `book.<number>.number` и счётчик `book.count`.

### 1. Добавить или обновить запись (`action: "add"`)
Если запись с таким `number` уже есть в списке, она обновится; если нет — добавится в конец:
```json
{
  "type": "smart",
  "join": "phonebook",
  "value": {
    "action": "add",
    "item": {
      "name": "Переговорная 05.300",
      "desc": "Тюмень · новый корпус",
      "number": "53001",
      "join": 411
    }
  }
}
```
*(Поле `"join"` задаёт digital-сигнал, который отправит панель при клике на эту строку; если его не указывать, ядро автоматически назначит `book.53001`.)*

### 2. Удалить запись по номеру (`action: "remove"`)
```json
{
  "type": "smart",
  "join": "phonebook",
  "value": {
    "action": "remove",
    "number": "53001"
  }
}
```

### 3. Загрузить весь список целиком или очистить (`set` / `clear`)
* **Заменить весь список:** `{"type":"smart","join":"phonebook","value":{"action":"set","items":[ ... ]}}`
* **Очистить список:** `{"type":"smart","join":"phonebook","value":{"action":"clear"}}`

## Воркфлоу с нейросетями (AI-Generation)

В репозитории доступны два специализированных промпт-файла под разные задачи:

### А. Генерация нового проекта с нуля (`AV-FULL-PANEL-SKILL.md`)
Используйте этот файл, когда нужно создать **целый интерфейс `index.html` с нуля** по текстовому ТЗ, наброску или скриншоту сторонней системы:
1. Передайте файл [`AV-FULL-PANEL-SKILL.md`](AV-FULL-PANEL-SKILL.md) как системную инструкцию вашей LLM (Claude, GPT, Gemini, Cursor) и приложите описание задачи или скриншот.
2. Сохраните сгенерированный код в файл (например, `my_panel.html`) рядом с `av-core.js` и `panel-editor.js`.
3. Откройте файл в браузере и нажмите **`E`** — все экраны, диалоги, слайдеры и join-сигналы сразу готовы к визуальной доводке в **Panel Editor**.

### Б. Добавление экранов и виджетов в существующий проект (`AV-SKILL.md`)
Используйте этот файл, чтобы **дополнять готовый шаблон** новыми страницами, модальными окнами или карточками:
1. Передайте файл [`AV-SKILL.md`](AV-SKILL.md) в контекст вашей LLM.
2. Опишите нужный экран или виджет (например: *«Сверстай экран управления климатом и шторами `page-climate`»*).
3. Скопируйте полученный HTML-код в буфер обмена.
4. Нажмите кнопку **`📋` (Вставить из буфера)** в верхней панели **Panel Editor** — редактор автоматически распознает тип экрана, назначит свободные join-ы, при необходимости добавит кнопку в нижнее меню и привяжет элементы к ядру `av-core.js`.

## Модуль видеостены (`LEDWall` v4)

Встроенный автономный виджет для управления многооконными видеостенами и видеопроцессорами. Поддерживает неограниченное количество экранов, автогенерацию SVG-миниатюр раскладок и безопасное дублирование карточек в **Panel Editor** (при ремапе join-ов в редакторе модуль подхватывает новые сигналы напрямую из DOM-атрибутов).

### 1. Размещение на экране
Добавьте пустой контейнер с атрибутом `data-lw-frame="<id>"` (должен совпадать с `id` в `window.LEDWALL_CONFIG.frames`):
```html
<div class="av-card p-4 flex flex-col gap-3" data-lw-frame="led1"></div>
```

### 2. Настройка раскладок и источников (`window.LEDWALL_CONFIG`)
* **Раскладки (`layouts`):** описывают сетку окон в процентах (`0–100%`) через хелпер `Z(id, x, y, w, h, prefix, fontSize, color)`. SVG-иконки кнопок раскладок строятся автоматически.
* **Источники (`sources`):** формируют сетку кнопок в модальном окне `#modal-led-source` (`[data-lw-src-grid]`).
* **Режим синхронизации (`controllerDriven`):**
  * `false` — локальный отклик (панель сразу меняет раскладку и подписывает источник в окне, параллельно отправляя команды TX);
  * `true` — строгое подтверждение от контроллера (UI обновляется только по входящим сигналам RX).

### 3. Протокол сигналов (TX / RX контракт)

| Направление | Тип | Join (пример) | Назначение |
| :--- | :--- | :--- | :--- |
| **TX** (Панель → Контроллер) | `Digital` | `led1.set.quad` | Импульс `1` при выборе раскладки «Четыре окна» |
| **TX** (Панель → Контроллер) | `Digital` | `led1.quad.a.open` | Импульс `1` при клике по окну `A` (открытие выбора источника) |
| **TX** (Панель → Контроллер) | `Digital` | `led.src.hdmi` | Импульс `1` при выборе источника «Ноутбук · HDMI» |
| **RX** (Контроллер → Панель) | `String` | `led1.layout` | ID активной раскладки (`"full"`, `"duo"`, `"quad"`, `"pip"`) |
| **RX** (Контроллер → Панель) | `String` | `led1.quad.a.name` | Имя текущего источника в окне `A` (`""` — сброс в заглушку) |

### 4. Программный API (`window.LEDWall`)
* `LEDWall.setLayout(frameId, layoutId)` — переключить раскладку на всех экземплярах видеостены `frameId`
* `LEDWall.addLayout(frameId, layoutObj)` / `removeLayout(frameId, layoutId)` — добавить или удалить раскладку на лету
* `LEDWall.addZone(frameId, layoutId, zoneObj)` / `removeZone(frameId, layoutId, zoneId)` — добавить или удалить окно внутри раскладки
* `LEDWall.setBackground(frameId, layoutId, css)` — изменить фон раскладки
* `LEDWall.setControllerDriven(bool)` — переключить режим синхронизации с контроллером
